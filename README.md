# Energy Reporting School

Interactive explainers on EU energy regulatory reporting: REMIT, EMIR, MiFIR, DORA, the electricity transparency rules, the framework of regulators behind them, and the controls that prove a report was right. A companion to the Nordic Power School, in the same design.

Open `index.html`, or view the live site on GitHub Pages. Every page is self-contained: no external scripts, fonts or images. Sources are listed in each lesson and on `references.html`.

Education only. Not legal advice. Rules current to October 2026.
